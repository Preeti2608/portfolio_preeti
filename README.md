## 📜 Certifications

The portfolio includes a dedicated **Certificates Vault** where visitors can explore my certifications and professional learning journey.

Adding a new certificate only requires:

1. Placing the PDF inside `assets/certificates`
2. Updating the certificate data

No HTML changes are required.
